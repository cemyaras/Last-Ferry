# Son Vapur — project rules

- Son Vapur is a 2D/2.5D atmospheric narrative game set in Istanbul, built with TypeScript, Phaser 3 and Vite.
- Preserve the established dark, rainy, melancholic Istanbul visual direction. New scenes must visually belong alongside the existing Kadıköy and Ferry scenes.
- Preserve working systems; avoid unnecessary rewrites. Develop iteratively with controlled scope.
- Do not add quests, inventory, combat, crafting, skill trees or other major systems unless explicitly requested.
- Preserve limited 2.5D player movement and use Y-based depth where appropriate.
- Prefer reusable SVG, Canvas and procedural graphics over third-party assets.
- Prioritize atmosphere, environmental movement, lighting and composition over feature count.
- After changes, run the project and fix errors or regressions introduced by the work before finishing; report unrelated existing issues without expanding scope.
